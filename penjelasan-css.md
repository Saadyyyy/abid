PENJELASAN PROPERTY CSS

1. COLOR

color digunakan untuk mengatur warna teks.

Contoh:
color: red;
color: #2563eb;

2. BACKGROUND

background digunakan untuk mengatur background elemen. Property ini dapat digunakan untuk mengatur beberapa nilai background sekaligus, seperti warna atau gradient.

Contoh:
background: linear-gradient(135deg, #2563eb, #7c3aed);

3. BACKGROUND-COLOR

background-color digunakan untuk mengatur warna latar belakang elemen.

Contoh:
background-color: blue;

4. WIDTH

width digunakan untuk mengatur lebar elemen.

Contoh:
width: 200px;

5. HEIGHT

height digunakan untuk mengatur tinggi elemen.

Contoh:
height: 100px;

6. MAX-WIDTH

max-width digunakan untuk membatasi lebar maksimal elemen.

Contoh:
max-width: 100%;

7. MIN-HEIGHT

min-height digunakan untuk mengatur tinggi minimum elemen.

Contoh:
min-height: 200px;

8. MARGIN

margin digunakan untuk mengatur jarak bagian luar elemen.

Contoh:
margin: 20px;
margin: 0 auto;

9. MARGIN-TOP

margin-top digunakan untuk mengatur jarak bagian luar di bagian atas elemen.

Contoh:
margin-top: 20px;

10. MARGIN-BOTTOM

margin-bottom digunakan untuk mengatur jarak bagian luar di bagian bawah elemen.

Contoh:
margin-bottom: 20px;

11. MARGIN-RIGHT

margin-right digunakan untuk mengatur jarak bagian luar di sebelah kanan elemen.

Contoh:
margin-right: 10px;

12. PADDING

padding digunakan untuk mengatur jarak bagian dalam antara isi dan border elemen.

Contoh:
padding: 20px;
padding: 10px 20px;

13. GAP

gap digunakan untuk mengatur jarak antar item di dalam Flexbox atau Grid.

Contoh:
gap: 20px;

14. BORDER

border digunakan untuk membuat garis pada tepi elemen.

Contoh:
border: 2px solid black;

15. BORDER-TOP

border-top digunakan untuk membuat atau mengatur border pada bagian atas elemen.

Contoh:
border-top: 1px solid black;

16. BORDER-COLOR

border-color digunakan untuk mengatur warna border.

Contoh:
border-color: blue;

17. BORDER-RADIUS

border-radius digunakan untuk membuat sudut elemen menjadi melengkung.

Contoh:
border-radius: 10px;
border-radius: 50%;

18. FONT

font digunakan sebagai shorthand untuk mengatur beberapa property font sekaligus.

Contoh:
font: italic 16px Arial, sans-serif;

19. FONT-FAMILY

font-family digunakan untuk mengatur jenis huruf.

Contoh:
font-family: Arial, sans-serif;

20. FONT-SIZE

font-size digunakan untuk mengatur ukuran teks.

Contoh:
font-size: 20px;

21. FONT-WEIGHT

font-weight digunakan untuk mengatur ketebalan teks.

Contoh:
font-weight: 700;

22. FONT-STYLE

font-style digunakan untuk mengatur gaya teks, misalnya normal atau italic.

Contoh:
font-style: italic;

23. LINE-HEIGHT

line-height digunakan untuk mengatur jarak antar baris teks.

Contoh:
line-height: 1.7;

24. LETTER-SPACING

letter-spacing digunakan untuk mengatur jarak antar huruf.

Contoh:
letter-spacing: 2px;

25. TEXT-ALIGN

text-align digunakan untuk mengatur posisi horizontal teks.

Contoh:
text-align: center;

26. TEXT-DECORATION

text-decoration digunakan untuk mengatur dekorasi pada teks, seperti garis bawah.

Contoh:
text-decoration: none;
text-decoration: underline;

27. TEXT-SHADOW

text-shadow digunakan untuk memberikan bayangan pada teks.

Contoh:
text-shadow: 3px 3px 5px gray;

28. DISPLAY

display digunakan untuk mengatur cara elemen ditampilkan.

Nilai yang digunakan pada file:
block
inline
inline-block
none
flex
grid

Contoh:
display: flex;

29. FLEX-DIRECTION

flex-direction digunakan untuk mengatur arah item di dalam Flexbox.

Contoh:
flex-direction: row;
flex-direction: column;

30. FLEX-WRAP

flex-wrap digunakan untuk menentukan apakah item Flexbox boleh berpindah ke baris berikutnya.

Contoh:
flex-wrap: wrap;

31. FLEX

flex digunakan untuk mengatur ukuran atau pembagian ruang item di dalam Flexbox.

Contoh:
flex: 1;

32. FLEX-SHRINK

flex-shrink digunakan untuk mengatur kemampuan item mengecil ketika ruang tidak cukup.

Contoh:
flex-shrink: 0;

33. JUSTIFY-CONTENT

justify-content digunakan untuk mengatur posisi item pada arah utama Flexbox.

Contoh:
justify-content: center;
justify-content: space-between;

34. ALIGN-ITEMS

align-items digunakan untuk mengatur posisi item pada arah silang Flexbox atau Grid.

Contoh:
align-items: center;

35. PLACE-ITEMS

place-items digunakan untuk mengatur align-items dan justify-items sekaligus pada Grid.

Contoh:
place-items: center;

36. GRID-TEMPLATE-COLUMNS

grid-template-columns digunakan untuk mengatur jumlah dan ukuran kolom pada CSS Grid.

Contoh:
grid-template-columns: repeat(3, 1fr);

37. GRID-TEMPLATE-ROWS

grid-template-rows digunakan untuk mengatur jumlah dan ukuran baris pada CSS Grid.

Contoh:
grid-template-rows: auto 260px auto;

38. GRID-COLUMN

grid-column digunakan untuk menentukan posisi atau area kolom sebuah item Grid.

Contoh:
grid-column: 1 / 3;

39. GRID-ROW

grid-row digunakan untuk menentukan posisi atau area baris sebuah item Grid.

Contoh:
grid-row: 2 / 3;

40. POSITION

position digunakan untuk menentukan metode penempatan elemen.

Nilai yang digunakan pada file:
relative
absolute
sticky

Contoh:
position: relative;

41. TOP

top digunakan untuk mengatur jarak elemen dari bagian atas sesuai sistem position.

Contoh:
top: 20px;

42. RIGHT

right digunakan untuk mengatur jarak elemen dari bagian kanan sesuai sistem position.

Contoh:
right: 20px;

43. OVERFLOW

overflow digunakan untuk mengatur apa yang terjadi jika isi elemen melebihi ukuran elemen.

Nilai yang digunakan pada file:
visible
hidden
scroll
auto

Contoh:
overflow: auto;

44. BOX-SHADOW

box-shadow digunakan untuk memberikan bayangan pada elemen.

Contoh:
box-shadow: 0 10px 25px rgba(0, 0, 0, 0.15);

45. OPACITY

opacity digunakan untuk mengatur tingkat transparansi elemen.

Nilai 1 berarti sepenuhnya terlihat.
Nilai 0 berarti sepenuhnya transparan.

Contoh:
opacity: 0.7;

46. CURSOR

cursor digunakan untuk mengatur bentuk kursor mouse ketika berada di atas elemen.

Nilai yang digunakan pada file:
pointer
help
not-allowed

Contoh:
cursor: pointer;

47. OBJECT-FIT

object-fit digunakan untuk mengatur bagaimana gambar atau video menyesuaikan ukuran wadahnya.

Nilai yang digunakan pada file:
cover
contain
fill

Contoh:
object-fit: cover;

48. TRANSITION

transition digunakan untuk membuat perubahan property menjadi lebih halus dan memiliki durasi.

Contoh:
transition: transform 0.3s ease;

49. TRANSFORM

transform digunakan untuk mengubah posisi, ukuran, atau rotasi elemen.

Contoh:
transform: translateY(-15px);
transform: scale(1.15);
transform: rotate(8deg);

50. BOX-SIZING

box-sizing digunakan untuk menentukan bagaimana width dan height menghitung padding dan border.

Nilai yang digunakan pada file:
content-box
border-box

Contoh:
box-sizing: border-box;

51. OUTLINE

outline digunakan untuk membuat garis di luar border elemen.

Contoh:
outline: none;

52. ACCENT-COLOR

accent-color digunakan untuk mengatur warna pada bagian kontrol form tertentu, seperti checkbox.

Contoh:
accent-color: green;

53. CONTENT

content digunakan untuk menambahkan isi pada pseudo-element seperti ::before dan ::after.

Contoh:
content: "🔥 ";

54. SCROLL-BEHAVIOR

scroll-behavior digunakan untuk mengatur perilaku saat halaman melakukan scroll.

Contoh:
scroll-behavior: smooth;

55. CSS VARIABLES

CSS Variables digunakan untuk menyimpan nilai yang dapat digunakan kembali.

Variabel biasanya dibuat menggunakan dua tanda minus.

Contoh:
--primary-color: #2563eb;

Untuk menggunakan variabel:
color: var(--primary-color);

56. CUSTOM PROPERTY

Custom Property adalah nama lain dari CSS Variables.

Contoh:
--border-radius: 12px;

57. BACKGROUND GRADIENT

Gradient digunakan untuk membuat perpindahan warna secara bertahap.

Contoh:
background: linear-gradient(135deg, blue, purple);

58. FIT-CONTENT

fit-content digunakan agar ukuran elemen menyesuaikan dengan ukuran kontennya.

Contoh:
width: fit-content;

59. OUTLINE DAN FOCUS

Property outline sering digunakan ketika elemen mendapatkan fokus.

Contoh:
input:focus {
    outline: none;
}

60. TRANSFORM FUNCTION

Beberapa function transform yang digunakan:

translateY()
Digunakan untuk memindahkan elemen secara vertikal.

scale()
Digunakan untuk memperbesar atau memperkecil elemen.

rotate()
Digunakan untuk memutar elemen.

Contoh:
transform: translateY(-10px);
transform: scale(1.1);
transform: rotate(10deg);

CATATAN

File CSS juga menggunakan konsep:
- Pseudo Class seperti :hover, :active, :focus, :checked, dan :disabled.
- Pseudo Element seperti ::before, ::after, dan ::placeholder.
- Media Query menggunakan @media untuk membuat tampilan responsive.

Contoh Media Query:
@media (max-width: 768px) {
    body {
        padding: 20px;
    }
}
